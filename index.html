GAS `Failed to fetch` / CORS 해결 4단계 방법

                

                
            

            

                

                    

                        1단계 Apps Script 배포 설정 변경
                    

                    
구글 시트 상단 메뉴 [확장 프로그램] > [Apps Script]를 클릭하여 에디터를 엽니다.

                


                

                    

                        2단계 [새 배포] 생성 클릭
                    

                    
우측 상단 [배포] > [새 배포]를 선택합니다. (기존 배포 수정 대신 반드시 '새 배포' 진행)

                


                

                    

                        3단계 (가장 중요) 액세스 권한 변경
                    

                    
    
                        
  • 유형: 웹 앱 (Web App)
    • 
                        
  • 다음 사용자 권한으로 실행: 나 (Me)
    • 
                        
  • 액세스 권한이 있는 사용자: 누구나 (Anyone) (★ 필수!)
    • 
                    

                    
※ '나만' 또는 'Google 계정이 있는 모든 사용자'로 선택 시 로그인 페이지로 이동하여 CORS 차단이 발생합니다.

                


                

                    

                        4단계 새 Web App URL 복사
                    

                    
배포 완료 후 생성되는 https://script.google.com/macros/s/.../exec URL을 복사하여 상단 대시보드 [GAS 콘솔] > URL 입력란에 붙여넣습니다.
